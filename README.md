## 🚀 About DataFlow.ai

DataFlow.ai is an Intelligent Document Processing (IDP) SaaS platform that transforms invoices, receipts, and forms into structured data instantly using AI-powered OCR technology.

## ✨ Key Features

- **AI-Powered OCR**: Advanced text extraction using Google Vision API and Gemini Flash
- **Invoice Processing**: Automatic extraction of vendor details, line items, and GST information
- **Excel Export**: Download structured data ready for accounting software
- **Pre-paid Credits**: Simple pay-as-you-go model with no subscriptions
- **Secure & Compliant**: Bank-grade encryption with automatic data deletion
- **Lightning Fast**: Process documents in seconds
